# 台股籌碼戰情室 (TW Stock Alpha)

這是一個結合宏觀籌碼（三大法人）與微觀籌碼（券商分點）的自動化分析系統。透過 Python 程式化交易思維，自動挖掘市場資金重心，追蹤高勝率分點，並將數據轉化為可視化的戰情儀表板。

## 功能亮點 (Alpha Features)

### 1. 贏家分點自動挖掘 (Smart Money Tracking)
不再手動輸入追蹤名單，系統會對全市場分點進行回測：
- **動態排名**：每日掃描交易數據，找出「勝率高」且「獲利金額大」的隱藏贏家。
- **隔日沖/波段偵測**：計算分點買進後的 T+1 日損益，識破誰是真正的操盤手。

### 2. 市場重心自動選股 (Active Selection)
拒絕倖存者偏差，讓市場資金告訴你該看哪支股票：
- **Active Mode**：自動抓取當日上市櫃「成交金額 (Turnover)」排行榜，鎖定市場最熱門的主戰場。
- **Dynamic Mode**：自動鎖定「法人持股佔比」剛創新高的股票。

### 3. 非同步高速爬蟲 (Async IO)
- 核心引擎全面升級為 Asyncio + Playwright，能同時併發抓取多檔股票的分點數據，效率提升數倍，並具備反偵測重試機制。

### 4. 雙戰情室儀表板
- **法人趨勢 (index.html)**：追蹤個股的外資、投信、自營商持股比重變化 (5/20/60日)。
- **分點戰情 (broker.html)**：展示「贏家名人堂」與「今日主力潛力股」清單。

## 每日操作流程 (SOP)

我們提供了一個自動化批次檔，能一次完成所有數據更新與分析流程。

### 方式一：一鍵執行 (推薦)

Windows 使用者請直接執行根目錄下的 **`daily_run.bat`**。

### 方式二：手動指令執行

若需個別執行特定步驟，請依序執行以下指令：

**步驟 1：更新宏觀數據**
抓取當日收盤價、三大法人買賣超，生成基礎數據。

```bash
python update_all.py

```

**步驟 2：更新微觀數據 (爬蟲)**
啟動爬蟲抓取分點進出明細。

* 模式 A (推薦)：抓取全市場成交金額前 50 大熱門股
```bash
python update_broker.py --mode active --limit 50

```


* 模式 B：抓取法人高持股股票
```bash
python update_broker.py --mode dynamic --limit 30

```



**步驟 3：計算績效與挖掘贏家**
回測分點獲利，產出贏家排名與潛力股清單。

```bash
python track_broker_profit.py

```

**步驟 4：啟動戰情室**
進入 docs 資料夾啟動網頁伺服器。

```bash
cd docs
python -m http.server

```

## 戰情室導覽

啟動伺服器後（預設 Port 8000），請用瀏覽器開啟：

### 1. 券商籌碼戰情室 (http://localhost:8000/broker.html)

* **贏家分點名人堂**：左側列出目前市場上勝率最高、獲利最穩的分點券商。
* **主力今日掃貨**：右側列出上述贏家分點今日正在買進的股票（跟單潛力股）。

### 2. 法人持股趨勢圖 (http://localhost:8000/index.html)

* 輸入股票代號（如 2330），查看外資、投信、自營商的歷史持股水位變化。
* 透過 5日 / 20日 / 60日 變化排行，找出法人剛開始佈局的標的。

## 專案結構

```text
.
├── daily_run.bat             # 一鍵自動化腳本
├── update_all.py             # 宏觀數據更新 (三大法人/股價)

│   ├── broker/               # 每日分點交易紀錄
│   └── ...
└── docs/                     # 前端網頁與 JSON 數據
    ├── index.html            # 法人趨勢頁面
    ├── broker.html           # 券商戰情室頁面
    └── data/                 # 供網頁讀取的 JSON 檔案
